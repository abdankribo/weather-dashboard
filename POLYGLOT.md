# Polyglot Implementations

This repository includes companion implementations for portfolio and learning purposes.

- JavaScript — browser UI
- Python — scripting/data logic
- Java — OOP implementation
- C++ — algorithm/system implementation
- Go — backend/service implementation
- Rust — systems/CLI implementation
- PHP — server-side implementation
- Kotlin — JVM implementation
- C# — .NET implementation

The implementations are intentionally separated under `polyglot/` so the original web application remains intact.
