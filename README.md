# Weather Dashboard

Dashboard cuaca interaktif dengan visual forecast, metric cards, hourly forecast dan weekly forecast.

## Fitur
- City search demo
- Current weather
- Temperature conversion
- Hourly forecast
- 7-day forecast
- Weather metrics
- Theme toggle
- Responsive UI

## Catatan
Data demo disiapkan agar project dapat berjalan tanpa API key. Adapter API dapat ditambahkan pada tahap berikutnya.
